#+Title: Dotfiles

GNU Stow-managed dotfiles. Each top-level directory is a stow package — stow it and files symlink into ~.

* AI Agent Deployment

This repo includes ~AGENTS.md~ at the root — compatible with Claude Code, Codex, Cursor, and any tool that reads agent manifests. Point your AI agent here and ask it to deploy what you need.

* Quick Start (Manual)

First install GNU Stow:

#+BEGIN_SRC bash
# macOS
brew install stow
# Debian/Ubuntu
sudo apt install -y stow
# Arch
sudo pacman -S stow
#+END_SRC

Then clone and stow what you want:

#+BEGIN_SRC bash
git clone https://github.com/linxichen/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow tmux -t ~       # deploy tmux config
stow oh-my-zsh -t ~  # deploy zsh config
#+END_SRC

Unstow or restow:

#+BEGIN_SRC bash
stow nvim -D -t ~    # remove
stow nvim -R -t ~    # restow
#+END_SRC

* Per-Package Setup

Some packages need external repos cloned or plugins installed after stowing. See ~AGENTS.md~ for the full manifest, or:

| Package     | Extra Setup |
|-------------+-------------|
| tmux        | Clone TPM: ~git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm~ then run ~install_plugins~ |
| oh-my-zsh   | Install oh-my-zsh first |
| vim         | Clone Vundle, run ~vim +PluginInstall +qall~ |
| nvim        | None — LazyVim self-bootstraps on first launch |
| spacemacs   | Clone spacemacs to ~~/.emacs.d~ |
| doom_emacs  | Clone doom to ~~/.config/emacs~, run ~doom install~ |
